# Γεωργία — Portfolio Website 💗

Premium, μοντέρνο και μινιμαλιστικό portfolio για **Social Media Content Creator & Graphic Designer**, με σκούρο κομψό φόντο, ροζ πινελιές και τυπογραφία Montserrat.

Φτιαγμένο με **HTML + Tailwind CSS + JavaScript**. Είναι 100% αυτόνομο — γραμματοσειρές και CSS φορτώνονται τοπικά, οπότε δουλεύει ακόμα και χωρίς internet.

## 📸 Πώς προσθέτω εικόνες στο Portfolio

Οι εικόνες εμφανίζονται **αυτόματα** — δεν χρειάζεται να πειράξεις καθόλου τον κώδικα!

1. Άνοιξε τον φάκελο της κατηγορίας, π.χ. `images/fastfood/`
2. Βάλε μέσα τις εικόνες με ονόματα **αριθμούς στη σειρά**:
   `1.jpg`, `2.jpg`, `3.jpg` … μέχρι `10.jpg`
3. Ανανέωσε τη σελίδα — έτοιμο! ✨

**Λεπτομέρειες:**
- Υποστηρίζονται: `.jpg`, `.jpeg`, `.png`, `.webp`
- Προτεινόμενη διάσταση: **1080 × 1350 px** (αναλογία 4:5, όπως τα Instagram posts)
- Μέχρι **10 εικόνες** ανά κατηγορία
- Ξεκίνα πάντα από το `1` με συνεχόμενη αρίθμηση
- Όσο ένας φάκελος είναι άδειος, εμφανίζονται κομψά placeholders

**Πορτρέτο hero:** βάλε τη φωτογραφία της Γεωργίας στο `images/profile/` με όνομα `georgia.jpg` (ή `.png` / `.webp`).

## ✏️ Πώς αλλάζω τα κείμενα

Όλα τα κείμενα βρίσκονται στο `index.html`. Τα σημεία που αλλάζουν συχνά είναι μαρκαρισμένα με σχόλιο:

```html
<!-- ✏️ ΑΛΛΑΞΕ ΕΔΩ: ... -->
```

Συγκεκριμένα:
- **Παρουσίαση & ρόλος** → ενότητα HERO
- **Κείμενο "Σχετικά με εμένα"** → ενότητα ΣΧΕΤΙΚΑ
- **Ονόματα επιχειρήσεων** → ενότητα ΣΧΕΤΙΚΑ (τα "Επιχείρηση 1-5" είναι placeholders)
- **Δεξιότητες & λόγοι συνεργασίας** → ενότητες ΔΕΞΙΟΤΗΤΕΣ / ΓΙΑΤΙ ΕΜΕΝΑ
- **Instagram, TikTok, Email, Τοποθεσία** → ενότητα ΕΠΙΚΟΙΝΩΝΙΑ και FOOTER

## 🎨 Χρωματική παλέτα & τυπογραφία

| Χρώμα | Κωδικός |
|---|---|
| Μαύρο (φόντο) | `#0F0F0F` |
| Ροζ (accent) | `#FF4FA3` |
| Λευκό | `#FFFFFF` |
| Ανοιχτό γκρι | `#F5F5F5` |

Η παλέτα ορίζεται στο `tailwind.config.js` και στο `css/style.css` (μεταβλητές `:root`).

**Τυπογραφία:** Montserrat για τους λατινικούς χαρακτήρες. Επειδή η Montserrat **δεν περιλαμβάνει ελληνικούς χαρακτήρες**, τα ελληνικά αποδίδονται με τη **Manrope** — μια γεωμετρική γραμματοσειρά στο ίδιο ακριβώς πνεύμα — ώστε όλο το site να δείχνει ενιαίο και premium. Η επιλογή γίνεται αυτόματα ανά χαρακτήρα (δες `css/fonts.css`).

## 🖥️ Πώς βλέπω το site τοπικά

**Προτεινόμενος τρόπος** (για να δουλεύει τέλεια η αυτόματη φόρτωση εικόνων):

```bash
# μέσα στον φάκελο του project
python3 -m http.server 8000
# και άνοιξε στον browser: http://localhost:8000
```

Εναλλακτικά, κάνε διπλό κλικ στο `index.html` — λειτουργεί κι έτσι, χωρίς internet.

---

## 🛠️ Για προχωρημένους: αλλαγές στο σχεδιασμό

Οι αλλαγές σε **κείμενα και εικόνες δεν χρειάζονται τίποτα** — απλώς αποθήκευση και refresh.

Αν όμως προσθέσεις **καινούριες κλάσεις Tailwind** στο `index.html` ή στο `js/main.js` (ή αλλάξεις την παλέτα στο `tailwind.config.js`), ξαναχτίσε το CSS:

```bash
npm install        # μία φορά μόνο
npm run build:css  # ξαναχτίζει το css/tailwind.css
```
